古典與現代密碼學原理

密碼學是資訊安全的基石。本平台獨立拆解「古典密碼學」與「現代密碼學」兩大演算法體系，協助學生建立從單純字元置換到高深數論演算法的系統化觀念。

1. 古典密碼學 (Classical Cryptography)

核心概念：字元位移、單表/多表替換、位置置換

運作原理： 古典密碼學建立在對明文字元進行「代換 (Substitution)」或「置換 (Transposition)」的基本操作上，運算完全可在紙筆間完成。

  • 凱撒密碼 (Caesar Cipher)： 透過將字母表按照固定位移量 (Shift) 平移進行單表替換。
  • 維吉尼亞密碼 (Vigenère Cipher)： 使用重複金鑰帶入對照表進行多表替換。
  • 籬笆密碼 (Rail Fence Cipher)： 將明文按照鋸齒狀規律交錯寫入多行籬笆中順序讀出。

2. 現代密碼學 (Modern Cryptography)

核心概念：非對稱數論、對稱區塊/金鑰流、單向雜湊碰撞

運作原理： 現代密碼學建立在計算複雜性理論之上，依賴嚴謹的數學難題確保安全性。

  • RSA 公鑰非對稱加密： 基於大整數質因數分解的困難度。
  • AES 對稱加密 (CTR 模式)： 利用金鑰流與明文進行 XOR 運算。
  • 單向雜湊與弱型態碰撞： MD5/SHA1 將任意長度輸入轉為固定長度 Digest。

7 大 CTF 題型深度系統化解析

深入探索各領域漏洞發生的底層機制、攻擊手法與常用破解分析工具。

1

古典密碼學 (Classical Cryptography)

底層原理： 建立在字元的「代換」與「位置置換」之上，不涉及高深數論，適合紙筆解密。

常見漏洞： 存在嚴重的「字母頻率特徵」。多表代換若金鑰過短，可透過 Kasiski 測試估算長度破解。

涵蓋題型： 凱撒移位密碼 (ROT13/Brute-force)、維吉尼亞多表密碼、籬笆位移密碼。

常用工具： CyberChef, dcode.fr, Python 腳本。

2

現代密碼學 (Modern Cryptography)

底層原理： 建立在計算複雜性理論與數論難題之上，取決於金鑰長度與隨機性。

常見漏洞： RSA 質數 p, q 過小遭分解；AES-CTR Nonce 重用導致 Key Stream 抵銷；MD5 弱型態 (0e) 碰撞。

涵蓋題型： RSA 質因數分解、AES 金鑰流重用分析、MD5 弱型態比較繞過。

常用工具： RsaCtfTool, Factordb, Hashcat, pycryptodome。

3

Web 漏洞利用 (Web Exploitation)

底層原理： Web 應用未對使用者輸入進行驗證，導致輸入資料被伺服器或資料庫當成指令執行。

常見漏洞： SQL 拼接語法繞過；XSS 注入觸發跨站腳本竊取 Cookie；LFI 相對路徑穿越讀取後端原始碼。

涵蓋題型： SQL Injection 萬能密碼、Reflected XSS 腳本注入、LFI 本地檔案包含。

常用工具： Burp Suite, sqlmap, dirsearch, Postman。

4

Pwn 二進位漏洞利用 (Binary Exploitation)

底層原理： C/C++ 等底層程式缺乏邊界檢查或記憶體管理不當，導致堆疊結構被破壞。

常見漏洞： 堆疊溢位覆寫 Return Address；格式化字串 (%p/%x) 窺探記憶體；UAF 記憶體懸空指標重用。

涵蓋題型： Stack Buffer Overflow, Format String Leak, Heap Use-After-Free。

常用工具： Pwntools, gdb (pwndbg/gef), checksec。

5

逆向工程 (Reverse Engineering)

底層原理： 將可執行檔反組譯或反編譯為組合語言，分析演算法與驗證金鑰邏輯。

常見漏洞： 比對函數 (CMP/strcmp) 缺乏混淆保護；未脫殼的執行檔可被直接搜尋字串。

涵蓋題型： XOR 加密算法逆向、x86 ASM 組合語言邏輯分析、UPX 脫殼與字串搜尋。

常用工具： IDA Pro, Ghidra, x64dbg, Cutter, UPX。

6

數位鑑識 (Digital Forensics)

底層原理： 從記憶體快取、網路封包 (pcap) 或損毀檔案中，還原攻擊者留下的數位痕跡。

常見漏洞： 傳輸敏感資訊未加密；損毀之圖檔 Magic Header 可被修復；記憶體殘留系統憑證。

涵蓋題型： PNG Magic Header 16進位修復、Wireshark HTTP 封包提取、Memory Dump 記憶體分析。

常用工具： Wireshark, Volatility, HxD, FTK Imager, foremost。

7

MISC 雜項與綜合 (Miscellaneous)

底層原理： 涵蓋無法歸類的綜合性安全技巧，包含圖片隱寫、特異語言與 AI 越獄等新興領域。

常見漏洞： 圖片 LSB 最低位元藏有隱密訊息；Esolang 邏輯洩漏；LLM 未對 Prompt 進行適當邊界過濾。

涵蓋題型： LSB 最低位元隱寫術、Brainfuck 直譯器執行、AI Prompt Injection 越獄測試。

常用工具： zsteg, Stegsolve, CyberChef, Python Pillow 庫。
